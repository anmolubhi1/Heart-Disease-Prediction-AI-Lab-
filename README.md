# ❤️ Heart Disease Prediction using Machine Learning

A machine learning project that predicts the likelihood of **Heart Disease** using clinical data.  
This project includes complete **Exploratory Data Analysis (EDA)**, a **Correlation Matrix**, and a **Logistic Regression Model**, built using **NumPy, Pandas, Matplotlib, Seaborn, and Scikit-Learn**.

---

## 📌 Project Overview

Heart disease remains one of the leading causes of death worldwide. Early prediction can help in timely diagnosis and treatment.  
This project builds a predictive model using machine learning techniques to classify whether a person is at risk of heart disease.

---

## 🚀 Features

- ✔️ Cleaned & preprocessed dataset  
- ✔️ Comprehensive **Exploratory Data Analysis (EDA)**  
- ✔️ Visualization using **Matplotlib & Seaborn**  
- ✔️ **Correlation Matrix** for feature relationships  
- ✔️ Model building with **Logistic Regression**  
- ✔️ Model evaluation using accuracy, confusion matrix, and classification report
